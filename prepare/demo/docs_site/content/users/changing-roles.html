Each user has one role for the whole organization: admin or viewer. See Roles for what each role can do.

Change a user's role

Only admins can change roles. Send the new role in a partial update of the user:

curl -s -X PATCH http://localhost:8000/v1/users/usr_4f9a2c1e \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"role": "admin"}'

The same endpoint changes a user's display name ({"name": "..."}). A user's email address cannot be changed through the API.

When the change takes effect

The role is part of the user's token. A role change applies to new tokens only. A token issued before the change keeps the old role until it expires, which takes at most 60 minutes. To take admin rights away immediately, deactivate the user, which rejects all of their tokens at once, and reactivate them after the old tokens have expired.

The last admin

An organization must always have at least one active admin. Demoting, deactivating or removing the last active admin fails with 409 last_admin. Promote someone else first.
