Removing a user takes them out of the whole organization. This is different from removing a member from a group, which only affects one group.

Removal cannot be undone. To take access away temporarily, deactivate the user instead.

What removal does

  • Removes the user from every group they belong to.
  • Rejects all of their tokens immediately.
  • Frees their email address, so you can invite them again later. A re-invited person starts with no groups.

Before you remove someone

A user who owns projects cannot be removed. The request fails with 409 owns_projects. Transfer their projects to someone else first.

Request

Only admins can remove users. You cannot remove yourself, and you cannot remove the last active admin.

curl -s -X DELETE http://localhost:8000/v1/org/members/usr_4f9a2c1e \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

Note the path: /v1/org/members/{user_id}, not /v1/users/{user_id}. There is no DELETE /v1/users/{user_id} endpoint.

Can I delete a user's data completely?

Not through the API. Removal deletes the user's membership in your organization; it does not erase records kept for security and billing purposes.
