Deleting a group removes the group itself. It does not delete or deactivate any users.

What deletion does

  • The members keep their accounts and their other groups.
  • Every project the group had access to loses that access. Members who could only see a private project through this group can no longer see it.
  • The group's name becomes available again.

Deleting a group cannot be undone. Creating a new group with the same name does not bring back its members or its project access.

Request

Only admins can delete groups.

curl -s -X DELETE http://localhost:8000/v1/groups/grp_7d2e91b0 \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

A successful deletion returns 204 with no body.

Check before you delete

List the projects the group can access first, so you know what will change:

curl -s "http://localhost:8000/v1/projects?group_id=grp_7d2e91b0" \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"
