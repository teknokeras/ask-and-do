Groups collect users so you can give them access to projects together. A typical group is a team, such as Platform or Support.

Create a group

Only admins can create groups.

curl -s -X POST http://localhost:8000/v1/groups \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Platform", "description": "Platform engineering", "members": ["usr_4f9a2c1e"]}'

Fields

FieldRequiredNotes
nameYes3 to 64 characters: letters, digits, spaces, hyphens and underscores.
descriptionNoUp to 280 characters.
membersNoA list of user IDs to add right away. All of them must be active users.

Naming rules

Group names are unique within the organization, and the check ignores case: if Platform exists, you cannot create platform. A duplicate name fails with 409 name_taken.

You can rename a group later. Renaming does not change its ID, so project access is kept.

Limits

  • An organization can have up to 200 groups.
  • A group can have up to 500 members.
  • There is no limit on how many groups one user can belong to.

Groups cannot contain other groups.
