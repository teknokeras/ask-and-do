User endpoints

Method and pathDescription
GET /v1/usersList users. Filters: q, role, status, group_id.
GET /v1/users/{user_id}Get one user.
POST /v1/usersCreate an active user. Body: email, name, role.
PATCH /v1/users/{user_id}Change name or role.
POST /v1/users/{user_id}/deactivateDeactivate a user.
POST /v1/users/{user_id}/reactivateReactivate a deactivated user.
POST /v1/users/{user_id}/xferTransfer all projects owned by the user. Body: to_user_id.

Organization membership

Method and pathDescription
DELETE /v1/org/members/{user_id}Remove the user from the organization. Permanent.

Invitation endpoints

Method and pathDescription
GET /v1/invitationsList invitations. Filter: status. Admins only.
POST /v1/invitationsInvite someone. Body: email, role, message.
POST /v1/invitations/{invitation_id}/resendResend and reset the expiry to 7 days. Up to 5 times.
DELETE /v1/invitations/{invitation_id}Revoke a pending or expired invitation.
