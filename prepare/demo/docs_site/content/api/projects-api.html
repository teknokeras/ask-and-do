Project endpoints

Method and pathDescription
GET /v1/projectsList projects the caller can see. Filters: q, owner_id, group_id, archived.
GET /v1/projects/{project_id}Get one project.
POST /v1/projectsCreate a project. Body: name, key, owner_id, visibility.
PATCH /v1/projects/{project_id}Change name, visibility or owner_id. The key cannot be changed.
POST /v1/projects/{project_id}/archiveArchive: make the project read-only.
POST /v1/projects/{project_id}/unarchiveMake an archived project editable again.
DELETE /v1/projects/{project_id}Delete permanently. The project must be archived.

Access endpoints

Method and pathDescription
GET /v1/projects/{project_id}/groupsList the groups the project is shared with.
PUT /v1/projects/{project_id}/groups/{group_id}Share the project with a group.
DELETE /v1/projects/{project_id}/groups/{group_id}Stop sharing the project with a group.

To move all of one user's projects to another user, see POST /v1/users/{user_id}/xfer in the Users API.
