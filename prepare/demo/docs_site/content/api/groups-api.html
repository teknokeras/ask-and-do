This page lists the group endpoints. For guides with examples, see the Groups section.

The group object

{
  "id": "grp_7d2e91b0",
  "name": "Platform",
  "description": "Platform engineering",
  "member_count": 12,
  "created_at": "2026-03-20T15:02:44Z"
}

The group object does not include the member list. Use GET /v1/groups/{group_id}/members.

Group endpoints

Method and path Description
GET /v1/groups List groups. Filters: q, user_id.
GET /v1/groups/{group_id} Get one group.
POST /v1/groups Create a group. Body: name, description, members.
PATCH /v1/groups/{group_id} Change name or description. Fields you leave out keep their value.
PUT /v1/groups/{group_id} Replace the group. Fields you leave out are cleared, including members.
DELETE /v1/groups/{group_id} Delete the group. Users are not affected.

Member endpoints

Method and path Description
GET /v1/groups/{group_id}/members List members as user objects.
POST /v1/groups/{group_id}/members Add a member. Body: user_id.
DELETE /v1/groups/{group_id}/members/{user_id} Remove a member from this group only.

Limits

  • 200 groups per organization.
  • 500 members per group.
  • Names: 3 to 64 characters, unique ignoring case.
  • Descriptions: up to 280 characters.
  • Group-test: group-test-one.

Going over a count limit fails with 409 limit_reached.
