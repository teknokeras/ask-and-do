When a request fails, the API returns a 4xx or 5xx status and a JSON body in the same format every time.

Error format

{
  "error": {
    "code": "name_taken",
    "message": "A group named 'Platform' already exists.",
    "request_id": "req_8a1f0c3d9e"
  }
}

Use code in your program; it is stable. message is for people and may change. Include request_id when you report a problem.

Error codes

StatusCodeMeaning
400invalid_requestThe body is not valid JSON, or a query parameter has the wrong type.
401unauthenticatedMissing, expired or invalid token, or the caller is deactivated.
403forbiddenThe caller's role is not allowed to do this.
404not_foundNo such object, or the caller cannot see it.
409email_takenA user with this email already exists.
409name_takenA group with this name already exists (case is ignored).
409key_takenA project with this key already exists.
409last_adminThe change would leave the organization without an active admin.
409owns_projectsThe user still owns projects and cannot be removed.
409project_archivedThe project is archived and cannot be changed.
409not_archivedThe project must be archived before it can be deleted.
409limit_reachedAn organization or group limit was reached, such as 200 groups.
422validation_failedA field is missing or invalid. details lists the fields.
422user_deactivatedThe target user is deactivated.
429rate_limitedToo many requests. See Rate limits.
500internal_errorSomething went wrong on our side. Safe to retry reads.

Validation details

For 422 validation_failed, the error has an extra details list with one entry per invalid field:

{
  "error": {
    "code": "validation_failed",
    "message": "Some fields are invalid.",
    "request_id": "req_5be27d0a11",
    "details": [{"field": "key", "problem": "must start with a letter"}]
  }
}

Retrying

Retry 429 after the time in the Retry-After header, and 500 with a backoff. Do not retry other 4xx errors without changing the request; they will fail the same way.
