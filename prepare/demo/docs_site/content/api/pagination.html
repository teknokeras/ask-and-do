Every endpoint that returns a list is paginated with cursors.

Pages and cursors

A list response has a data array and a next_cursor. Pass the cursor back to get the next page. When next_cursor is null, you have reached the last page.

curl -s "http://localhost:8000/v1/users?limit=100&cursor=eyJpZCI6InVzcl8wYjdjIn0" \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"
ParameterDefaultNotes
limit501 to 200. Larger values fail with 400 invalid_request.
cursornoneThe next_cursor from the previous page. Treat it as opaque.

Lists are sorted by creation time, oldest first. A cursor stays valid for 24 hours.

Filtering users

ParameterExampleMatches
q?q=anaName or email starting with the text, ignoring case.
role?role=adminUsers with this role.
status?status=deactivatedUsers with this status. Without it, both statuses are returned.
group_id?group_id=grp_7d2e91b0Members of this group.

Filtering groups

ParameterExampleMatches
q?q=platGroup name starting with the text, ignoring case.
user_id?user_id=usr_4f9a2c1eGroups this user belongs to.

Filtering projects

ParameterExampleMatches
q?q=payProject name or key starting with the text, ignoring case.
owner_id?owner_id=usr_4f9a2c1eProjects owned by this user.
group_id?group_id=grp_7d2e91b0Projects shared with this group.
archived?archived=trueArchived projects only. Default false.

Filters can be combined. They always apply on top of what the caller is allowed to see.
