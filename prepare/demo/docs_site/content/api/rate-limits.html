Rate limits protect the API from runaway scripts. Limits apply per token, not per user or per IP address.

Limits

RequestsLimit
All requests300 per minute
Writes (POST, PUT, PATCH, DELETE)30 per minute, counted inside the 300
Invitations sent or resent20 per hour per organization

Headers

Every response tells you where you stand:

  • X-RateLimit-Limit: the limit for this kind of request.
  • X-RateLimit-Remaining: requests left in the current minute.

When you hit a limit

The API answers 429 rate_limited with a Retry-After header in seconds. Wait that long and retry. Requests that got 429 were not carried out, so retrying a write does not apply it twice.

Higher limits

Limits cannot be raised per organization.
