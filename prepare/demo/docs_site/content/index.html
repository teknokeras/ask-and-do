Larkspur is an admin service for an organization's workspace. It keeps track of who is in your organization, which groups they belong to, and which projects those groups can see. Everything in Larkspur can be done through the HTTP API described in these docs.

What you can do

  • Users: create accounts directly or invite people by email, change roles, and deactivate or remove people.
  • Groups: create groups, add and remove members, and update group details.
  • Projects: create projects, give groups access, archive them and transfer ownership.

Where to start

If you are new to Larkspur, read Core concepts first, then follow the Quickstart to make your first API calls. The permission matrix lists what each role is allowed to do.

Getting help

Common questions are answered in the FAQ. Changes to the API are listed in the changelog.
