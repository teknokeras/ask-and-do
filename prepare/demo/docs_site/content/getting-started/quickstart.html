This quickstart lists the users in your organization, creates a group, and adds a member to it. You need an admin token for the last two steps.

Before you begin

You need an API token. Tokens are issued by your organization's sign-in service, not by Larkspur. See Authentication for what a token contains and how long it lasts.

All examples use the base URL http://localhost:8000/v1. Store your token in an environment variable so it does not end up in your shell history:

export LARKSPUR_TOKEN="paste-your-token-here"

Step 1: list users

Any role can list users.

curl -s http://localhost:8000/v1/users \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

The response is a page of users. Lists return at most 50 items unless you ask for more; see Pagination and filtering.

{
  "data": [
    {"id": "usr_4f9a2c1e", "email": "ana@example.com", "name": "Ana Silva",
     "role": "admin", "status": "active"}
  ],
  "next_cursor": null
}

Step 2: create a group

Creating a group needs the admin role. Group names must be unique in your organization.

curl -s -X POST http://localhost:8000/v1/groups \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Platform", "description": "Platform engineering"}'

Step 3: add a member

Use the group ID from the previous response and a user ID from step 1.

curl -s -X POST http://localhost:8000/v1/groups/grp_7d2e91b0/members \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "usr_4f9a2c1e"}'
