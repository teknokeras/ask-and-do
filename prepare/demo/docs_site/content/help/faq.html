Short answers, with links to the full pages.

Users

Should I create or invite a user?

Invite when the person should confirm and choose their own name. Create when you need the account active right away, for example for a service account. See Create vs invite.

Why can't I find someone I invited?

Invited people are not users until they accept, so they are not in GET /v1/users. Look in GET /v1/invitations?status=pending.

An invitation expired. Do I need to send a new one?

No. Resend it: that resets the expiry to 7 days. You can resend up to 5 times.

Can I permanently delete a user?

The closest is removing them from the organization, which cannot be undone. There is no endpoint that erases all of a user's records.

Can I change a user's email address?

Not through the API. Remove the user and invite the new address, or create a new user.

I demoted an admin but they can still make changes. Why?

Their current token still carries the admin role. It stops working within 60 minutes. To cut access immediately, deactivate them. See When the change takes effect.

Groups

I updated a group and all its members disappeared.

You probably used PUT without a members list. PUT replaces the whole group. Use PATCH to rename a group. See Updating groups.

Can a group contain other groups?

No. Groups contain users only.

Is removing a member from a group the same as removing them from the organization?

No. Removing a group member affects that group only. Removing someone from the organization takes them out of everything. See Remove a member.

Projects

Can I rename a project key?

No. Keys are permanent. You can change the project's display name.

Can I restore a deleted project?

No. Deletion is permanent. Archive projects you might need again.

Can I share a project with one person?

Not directly. Projects are shared with groups. Create a group with that person in it.

API

How long is a token valid?

60 minutes. See Authentication.

How many items does a list return?

50 by default, up to 200 with limit. See Pagination and filtering.

I got a 404 for a project I know exists.

You probably have a viewer token and the project is private and not shared with any of your groups. The API returns 404 instead of 403 so it does not reveal private project IDs.
