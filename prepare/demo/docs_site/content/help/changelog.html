Changes to the Larkspur API, newest first. All changes in v1 are backward compatible unless marked Breaking.

v1.4 (2026-10-20)

  • Added PATCH /v1/groups/{group_id} to change a group's name or description without touching its members. Before this release, PUT was the only way to update a group.
  • Added the group_id filter to GET /v1/projects.

v1.3 (2026-09-02)

  • Invitations can be resent up to 5 times. Earlier there was no limit.
  • Expired invitations can now be resent instead of being sent again from scratch.
  • Breaking: GET /v1/projects no longer returns archived projects by default. Add ?archived=true to see them.

v1.2 (2026-07-15)

  • Added POST /v1/users/{user_id}/xfer to transfer all of a user's projects at once.
  • Removing a user who owns projects now fails with 409 owns_projects instead of leaving the projects without an owner.

v1.1 (2026-06-03)

  • Added internal project visibility.
  • Raised the group member limit from 200 to 500.

v1.0 (2026-05-01)

  • First stable release of the Larkspur API.
