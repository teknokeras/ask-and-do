A project has a display name, a short key, one owner and a visibility setting.

Create a project

Only admins can create projects.

curl -s -X POST http://localhost:8000/v1/projects \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Payments", "key": "PAY", "visibility": "private"}'

Fields

FieldRequiredNotes
nameYes1 to 80 characters. Does not have to be unique.
keyYesSee Project keys.
owner_idNoAn active user. Defaults to the caller.
visibilityNoprivate (default) or internal. See Project access.

Project keys

The key is a short code that identifies the project, such as PAY or WEB2.

  • 2 to 10 characters, uppercase letters and digits only.
  • Must start with a letter.
  • Unique within the organization, including archived projects.
  • Cannot be changed after the project is created. To use a different key, create a new project.

A key that is already used fails with 409 key_taken. A key that breaks the format rules fails with 422 validation_failed.

Editing a project

Change the name, visibility or owner later with a partial update. The key is not accepted here.

curl -s -X PATCH http://localhost:8000/v1/projects/prj_51c0de77 \
  -H "Authorization: Bearer $LARKSPUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Payments Platform"}'

Limits

An organization can have up to 1,000 projects. Archived projects count toward this limit.
