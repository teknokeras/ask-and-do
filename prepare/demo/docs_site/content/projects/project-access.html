Who can see a project depends on its visibility and on which groups it is shared with. Access is always shared with groups, never with individual users. To share a project with one person, put them in a group.

Visibility

VisibilityWho can see the project
privateThe owner, all admins, and members of groups the project is shared with.
internalEvery active user in the organization.

New projects are private unless you set visibility when creating them.

Seeing a project is read access only. Changing a project always needs the admin role, whatever the visibility; see the permission matrix.

Share a project with a group

curl -s -X PUT http://localhost:8000/v1/projects/prj_51c0de77/groups/grp_7d2e91b0 \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

Sharing again with a group that already has access does nothing and returns 200.

Stop sharing with a group

curl -s -X DELETE http://localhost:8000/v1/projects/prj_51c0de77/groups/grp_7d2e91b0 \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

List the groups of a project

curl -s http://localhost:8000/v1/projects/prj_51c0de77/groups \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

Rules

  • Only admins can share or stop sharing a project.
  • Access of an archived project cannot be changed (409 project_archived).
  • A project can be shared with up to 50 groups.
