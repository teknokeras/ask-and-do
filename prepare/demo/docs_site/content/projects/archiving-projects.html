Archiving makes a project read-only. Use it when work on a project has finished but people may still need to look at it. Archiving can be undone at any time.

What archiving does

  • The project can still be viewed by everyone who could see it before.
  • Its name, visibility, owner and group access cannot be changed. Attempts fail with 409 project_archived.
  • It is hidden from GET /v1/projects unless you add ?archived=true.
  • Its key stays reserved, and it still counts toward the 1,000-project limit.

Archive a project

Only admins can archive projects.

curl -s -X POST http://localhost:8000/v1/projects/prj_51c0de77/archive \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

Unarchive a project

curl -s -X POST http://localhost:8000/v1/projects/prj_51c0de77/unarchive \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

Archive or delete?

Archive in almost every case. Deleting a project is permanent and only possible after the project has been archived.
