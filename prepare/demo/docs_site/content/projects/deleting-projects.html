Deleting a project is permanent. Larkspur keeps no copy, and support cannot restore a deleted project. In most cases you want to archive the project instead.

Requirements

  • Only admins can delete projects.
  • The project must be archived first. Deleting a project that is not archived fails with 409 not_archived.

Request

curl -s -X DELETE http://localhost:8000/v1/projects/prj_51c0de77 \
  -H "Authorization: Bearer $LARKSPUR_TOKEN"

A successful deletion returns 204 with no body.

After deletion

  • The project's key becomes available again for a new project.
  • The project no longer counts toward the project limit.
  • Group access to the project is removed. The groups themselves are not changed.
